# Дарина Ноговицына — сайт курсов подготовки к ЕГЭ и ОГЭ

Одностраничный адаптивный сайт на чистом HTML, CSS и JavaScript. Визуальная концепция: редакционная типографика, спокойный почти белый фон, графитовый текст и один основной синий акцент. Без UI-библиотек, градиентных декораций и выдуманных социальных доказательств.

## Структура
- `index.html` — структура страницы, тексты и ссылки на Telegram-направления.
- `styles.css` — дизайн-система и адаптивная вёрстка.
- `script.js` — доступное мобильное меню и автоматический год в подвале.

## Направления
- Физика ЕГЭ/ОГЭ — https://t.me/Alfred_physx_bot
- Математика ЕГЭ — https://t.me/PF_Math_bot
- Русский язык ЕГЭ — https://t.me/Gog_ya_bot
- Математика ОГЭ — https://t.me/M_OGE_bot

Ссылки перенесены из скриншота, предоставленного в разговоре. Перед публикацией проверьте, что каждый бот актуален и действительно относится к указанному курсу.

## Что нужно подтвердить перед публичным запуском
1. Кто именно ведёт занятия по каждому предмету и какова роль Дарины в проекте.
2. Программа, расписание, дата старта, цена и размер каждой группы.
3. Есть ли проверка домашних заданий, обратная связь и возможность задавать вопросы.
4. Условия оплаты, возврата и правила доступа к материалам.
5. Любые отзывы, баллы и результаты учеников — только реальные, проверяемые и опубликованные с разрешения.

Текст страницы сознательно не обещает конкретный балл и не приписывает Дарине неподтверждённые квалификации или результаты. Утверждения о групповом формате описывают общие преимущества такого подхода; детали конкретного курса нужно подтвердить.

## Запуск
Откройте `index.html` в браузере или включите GitHub Pages: **Settings → Pages → Deploy from a branch → main → /(root)**.
