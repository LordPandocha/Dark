# Дарина Ноговицына — сайт подготовки к ЕГЭ и ОГЭ

Одностраничный адаптивный сайт на чистом HTML, CSS и JavaScript. Визуальная идея — «живой конспект»: бумажная сетка, чернильно-синие элементы, красная корректировка, жёлтый маркер, скруглённые панели и выразительные кнопки. Анимационные приёмы изучены по HTML-референсу, но композиция, иллюстрации, тексты и реализация сделаны для этого проекта отдельно.

## Анимации и интерактивность
- Заголовок первого экрана появляется по буквам с последовательной задержкой.
- Рисованное подчёркивание и маркерная подсветка проявляются штрихом.
- SVG-формулы и пиктограммы прорисовываются по контуру.
- Декоративные листы и стикеры слегка плавают; окружности и значок двигаются по циклу.
- Бегущая строка с предметами останавливается при наведении.
- Верхняя полоска показывает прогресс прокрутки страницы.
- Карточки и разделы появляются при входе в область видимости; карточки поднимаются и отбрасывают контрастную тень при наведении.
- Кнопки имеют анимированный блик, смещение и выразительную «чернильную» тень.
- На устройствах с мышью мягкий блик на иллюстрации первого экрана следует за курсором.
- Мобильное меню закрывается по Escape; поддерживается системная настройка `prefers-reduced-motion`.

## Файлы
- `index.html` — структура, тексты и SVG-графика.
- `styles.css` — дизайн-система, адаптивная сетка и анимации.
- `script.js` — разбиение заголовка на буквы, прокрутка, появление разделов и мобильное меню.
