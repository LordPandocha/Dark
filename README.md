# Dark — сайт Дарины Ноговицыной

Адаптивный русскоязычный landing page для групповой подготовки к ЕГЭ/ОГЭ.

## Файлы
- `index.html` — структура и контент страницы.
- `styles.css` — дизайн-система, сетки, адаптивность и состояния.
- `script.js` — доступное мобильное меню и год в подвале.

## Запуск
Это статический сайт: откройте `index.html` в браузере или опубликуйте репозиторий через GitHub Pages (Settings → Pages → Deploy from a branch → `main` → `/ (root)`).

## Перед публикацией проверьте
1. Подтвердите, что Telegram-боты в карточках относятся к курсам и доступны для набора.
2. Добавьте согласованную биографию Дарины и проверяемые факты о преподавателях/методике.
3. Укажите реальное расписание, стоимость, размер группы, правила оплаты/возврата и формат обратной связи.
4. Добавляйте отзывы и результаты учеников только с разрешения и с подтверждёнными данными.
5. При наличии — замените графическую композицию в первом экране на авторскую фотографию, на которую есть права.

Контент намеренно не содержит выдуманных отзывов, результатов экзаменов или неподтверждённых обещаний. Ссылки Telegram перенесены из предоставленного скриншота и требуют проверки перед публичным запуском.
