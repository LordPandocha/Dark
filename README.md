# Дарина Ноговицына — сайт подготовки к ЕГЭ и ОГЭ

Одностраничный адаптивный сайт на HTML, CSS и JavaScript. Визуальная идея — «живой конспект»: бумажная сетка, выразительная типографика, скруглённые панели и рисованные схемы. Главный интерактивный элемент — полноэкранный каталог направлений с отдельной анимированной сценой для каждого предмета.

## Интерактивный выбор направления
Нажмите «Подобрать курс» / «Найти свой курс». Каталог открывается на весь экран в композиции из двух частей:
- **Слева:** название курса, короткое описание, теги и выбор из четырёх направлений.
- **Справа:** большая SVG-сцена с графиками, формулами, геометрией или разбором текста, которая меняется вместе с выбранным предметом.
- При смене предмета срабатывает цветовой wipe-переход, рисунок появляется по контуру, частицы и карточки входят с задержками.
- Сами варианты направления появляются по очереди. Выбранный пункт подсвечивается, CTA ведёт в соответствующий Telegram-бот.
- Закрытие — крестик или Escape; после закрытия фокус возвращается к кнопке, открывшей каталог. Есть управление стрелками вверх/вниз.
- На мобильных устройствах сцена переходит под список курсов, сохраняя анимации и взаимодействие.

## Motion-система
- Посимвольное появление главного заголовка, прорисовка SVG и маркерное подчёркивание.
- Появление блоков при прокрутке, progress bar и бегущая строка.
- Плавающие элементы, параллаксный блик и интерактивные состояния кнопок.
- Последовательные entrance-анимации, SVG line-draw, переходы между сценами и motion-карточки.
- Учитывается системная настройка `prefers-reduced-motion`.

## Что изучалось как технические референсы
Это не копирование готового сайта, а применение подходов к хореографии движения и интерактивным состояниям:
- [Truus.co Awwwards Website](https://github.com/Thakuma07/Truus.co-Awwward-Website) — GSAP-взаимодействия, elastic cards, SVG draw и page transitions.
- [Raft Landing Page](https://github.com/Temitayo-spec/Raft-Landing-Page) — композиция и сочетание GSAP с Framer Motion.
- [Jesko Jets Scroll Animation](https://github.com/Thakuma07/JeskoJets-ScrollAnimation) — scroll-driven сцены, глубина и layered motion.
- [PRIOR GSAP Animated Template](https://github.com/Relaxkartikey/prior-gsap-animation-portfolio-website-template) — clip-path переходы и анимации, привязанные к скроллу.

## Файлы
- `index.html` — структура, тексты, SVG-сцены и интерактивный каталог.
- `styles.css` — визуальная система, адаптивная сетка и motion.
- `script.js` — меню, прокрутка, выбор предмета, переходы и доступность.
