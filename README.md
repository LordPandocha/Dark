# Дарина Ноговицына — сайт курсов подготовки к ЕГЭ и ОГЭ

Адаптивный лендинг на чистом HTML, CSS и JavaScript. Визуальная система: светлый лавандово-серый фон, насыщенный фиолетово-синий акцент, мятные детали, скруглённые поверхности и pill-кнопки.

## Интерактивность
- Анимация появления первого экрана и плавающие декоративные элементы.
- Бегущая строка с предметами.
- Появление блоков при прокрутке страницы.
- Анимации карточек и кнопок при наведении/нажатии.
- Блик, следующий за курсором на иллюстрации первого экрана.
- Мобильная навигация с обработкой клавиши Escape.
- Уважение настройки `prefers-reduced-motion`.

## Файлы
- `index.html` — разметка и тексты.
- `styles.css` — дизайн-система, адаптивность, состояния и анимации.
- `script.js` — мобильное меню, reveal-анимации и взаимодействие с первым экраном.
